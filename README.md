# DEADFACE CTF 2026 — Writeups

Technical write-ups and solutions from **DEADFACE CTF 2026**, a free, online, jeopardy-style Capture the Flag competition hosted by Cyber Hacktics.

**Competition dates:** October 17–18, 2026

This repository documents challenge-solving approaches, technical analysis, tools, and lessons learned throughout the competition, with the goal of sharing knowledge and helping others learn cybersecurity.
